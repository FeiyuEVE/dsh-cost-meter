# v1.7.0 更新

## 新增:调用明细落 SQLite,页面统计以 SQLite 为数据源(issue #78)

### 1. 直接挂钩 LLM 调用,逐次写入 SQLite

宿主在 `llm/stream` 瀑布上已有的计费包裹(与账本同一入口)之外,新增调用明细库
`$DSH_HOME/storages/cost-meter/calls.sqlite`(Node 内置 `node:sqlite`,与宿主
session-query 同驱动)。每次模型调用写入一行,字段:

- 工作区:会话 cwd(经 `session/created` 追踪,`session/event` 瀑布同源);
- 会话 id / 会话标题(`session/title` 事件实时更新);
- 发起时间(at_ms,宿主时区日键/月键索引);
- token 桶:输入 / 输出 / 缓存命中(缓存触发)/ 缓存写入 / reasoning;
- 成本:统一人民币(cost_rmb)与 API 渠道人民币(api_cost_rmb),与账本同源同值。

### 2. 供应商模型货币类型配置

- 第三方价格表支持**表级**(`prices.providers.<id>.currency`)与**模型级**
  (`models.<id>.currency`)币种配置,设置页「拓展价格表」厂商标题行与模型价格卡
  各提供 USD/CNY 下拉;
- 生效币种优先级:模型级显式 → DeepSeek 峰谷主表跟随官方价币种(`prices.currency`)
  → 供应商表级 → USD;
- 计费按生效币种折算:人民币价模型(如部分国产厂商按元报价)不再被强制按美元价入账,
  会话徽章/账本/统计三处同口径。

### 3. 整体花费口径统一人民币

sqlite 行的成本恒以 RMB 存储:CNY 价目原值入账,USD 价目按展示汇率折算入账;
下发页面 wire 时按当前汇率折回美元,客户端既有展示管道(× 汇率)往返回到人民币,
历史金额随汇率调整稳定(人民币口径)。

### 4. 页面整体统计基于 sqlite

- 今日/本月/累计卡片、90 天历史、当日会话明细、跨日会话排行、预算已用金额全部改查
  调用明细库;
- 升级前账本历史以聚合行一次性幂等导入(`(day_key, session_id)` 唯一索引,
  INSERT OR IGNORE),统计无缝衔接、不重复计数;
- 配置变更与账本联动重算:`__local__`/本地模型归零、Plan 分类重拆、官方价币种切换
  时调用明细随账本同步(实时行就地重算、迁移行按重算后账本重建);
- 清空历史(resetHistory)同步清空调用明细。

### 5. 依赖升级

`@deepseek-ai/dsh-credentials` / `@deepseek-ai/dsh-home-paths` 升至与本工作区
deepseek-harness 一致的 `0.1.2-alpha.1`;该版本尚未发布到 npm,本地安装经
`pnpm-workspace.yaml` 的 overrides 重定向到工作区源码目录(link: 链接)。
端侧 `dsh plugin add` 安装时需宿主提供同版本(或更高)的这两个包。

### 6. 多 profile 共用同一份 sqlite 与配置

- DSH home 是单根(`$DSH_HOME` 或 `~/.dsh`),profile 只是
  `$DSH_HOME/profiles/<name>` 下的目录——web / acp / headless 等 profile 的
  调用明细库(`storages/cost-meter/calls.sqlite`)与账本配置
  (`storages/cost-meter/ledger.json`)天然同根,各 profile 进程读写同一份数据;
- 并发加固:调用明细库 `PRAGMA busy_timeout = 5000`(WAL 下多进程同时写等待
  而非 SQLITE_BUSY 互丢记录),迁移行重建(rebuildAggregates)包事务
  (BEGIN IMMEDIATE),并发触发重算时读侧不会看到中间态;
- 实时写库失败(磁盘满/锁超时等)不打断模型流,响亮告警;账本已入账的数据
  会在下次启动以聚合行补平该日统计。

### 7. 安装前历史回填 + 会话标题显示

- **一次性回填脚本** `node scripts/backfill-calls-sqlite.mjs`:把插件安装前(以及
  任何尚未入库的)会话消耗统计从会话日志直写 sqlite 调用明细,与实时计费同源
  回放(逐事件计价、fork 种子剔除、包装层指纹去重、标题取日志最后一次
  `session/title`);去重按 `(day_key, session_id)` 对调用明细现有全部行(实时行
  与迁移行)判重——已存在的会话只补空标题、金额绝不动,可重复执行增量补齐;
  与运行中的 dsh 并发安全(WAL + busy_timeout,账本只读不落盘)。
- **Web UI 会话列表显示标题**:恢复/回放会话的 `session/title` 事件不会重发到
  firehose,插件在 `session/created` 时直接从会话日志取最后一次标题,保证恢复
  会话的实时调用行也带标题;「今日会话 / 会话排行 / 历史明细」从截断的会话 id
  改为显示会话标题(无标题会话仍回落短 id)。

## 升级说明

- 首次启动自动把现有账本历史导入调用明细库(幂等),无需手工操作;
- sqlite 文件与 ledger.json 同目录,删除可重建(下次启动从账本重新导入);
- 页面统计不再受 `historyDays` 裁剪影响——sqlite 保留全部调用,历史记录上限仍按
  90 天展示,「累计」卡片为全量累计。
